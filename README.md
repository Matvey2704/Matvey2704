##  Обо мне

Проектирую адаптивные интерфейсы по макетам Figma, интегрирую REST API и выстраиваю управление состоянием (Redux Toolkit, RTK Query, React Query, Pinia). Умею закрывать задачу целиком: от интерфейса до базы данных. Сам спроектировал full-stack сервис на Next.js + PostgreSQL + Prisma с JWT-авторизацией с нуля.

Кроме фронтенда поддерживаю продакшен-магазин на CS-Cart (PHP, MySQL): диагностика производительности, оптимизация БД, защита от атак, работа с legacy-кодом без документации.

 **Сейчас открыт к предложениям** по Frontend / Fullstack-разработке.

##  Проекты

###  DevSpace: персональный ежедневник разработчика
**Next.js 16 · React 19 · TypeScript · PostgreSQL (Neon) · Prisma · Tailwind · shadcn/ui · Vercel**

Full-stack сервис, который я спроектировал и сделал сам: API на Route Handlers, схема БД и миграции, собственная JWT-авторизация (httpOnly cookie, без NextAuth/Clerk). Проекты с прогрессом, задачи, календарь, аналитика, фокус-режим с таймером.

###  Users Dashboard: админ-панель (заказной проект)
**Vue 3 · TypeScript · Pinia · Vue Router · Vite · SCSS**

Панель для базы из 2 500+ пользователей: поиск, комбинированная фильтрация, сортировка, пагинация с синхронизацией состояния между страницами, переиспользуемые компоненты.
